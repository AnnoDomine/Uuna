# 🚀 Getting Started

[⬅️ Back to Home](../Home.md)

Once your data is integrated, you can start interacting with the agents.

## 1. Start the Librarian (CLI)

Interact with the all-knowing Librarian directly from your terminal:

```bash
python3 Tools/agents/librarian.py
```

## 2. Launch the Web Interface

For a visual exploration of the database and research tasks:

```bash
python3 Tools/web/db_gui.py
```

Open your browser at `http://127.0.0.1:8002`.

## 3. Creating a Research Task

When the Librarian encounters a question it cannot answer, it will automatically spawn a **Task ID**. You can track the **Courier**'s progress through the logs or the Web UI.

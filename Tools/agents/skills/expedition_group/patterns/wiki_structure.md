# Pattern: Wiki Structure

## Infobox Patterns
Warcraft Wiki uses standard infoboxes for entities. You should prioritize data from these sections:
- **`Intro`**: General summary of the entity.
- **`Location`**: Geographic data.
- **`Status`**: Whether the entity is still in-game or removed.
- **`Patches`**: Vital for identifying which build introduced or modified the entity.

## Link Consistency
Entities in the wiki are often categorized.
- `Quest:X` -> Links to quest details.
- `Character:X` -> Links to NPC details.
- `Spell:X` -> Links to spell/mechanic details.

Use these category markers to refine your search queries.

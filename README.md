# Uuna Want Something

**Uuna Want Something** ist ein World of Warcraft Addon, das speziell entwickelt wurde, um Interaktionen mit dem Haustier **Uuna** zu protokollieren und zu verfolgen. Es bietet ein persistentes Logbuch, Aura-Tracking und Debug-Funktionen.

## Features

- **Story Log**: Protokolliert alle Dialoge und Ereignisse im Zusammenhang mit Uuna.
- **Aura Tracker**: Überwacht gewonnene und verlorene Auras des Spielers.
- **Quest Tracker**: Behält den Überblick über Uunas geheime Quests und Fortschritte.
- **Debug Log**: Protokolliert Spielereignisse (Events) zur Fehlerbehebung und Analyse.
- **Minimap Button**: Schneller Zugriff auf das Story-Log.
- **Summon Shortcut**: Uuna kann direkt über das Addon-Menü beschworen werden.

## Verwendung

- Öffne das Hauptfenster mit dem Befehl `/uuna` oder über das Minimap-Icon.
- Im Hauptfenster ("Uuna Story Log") kannst du den Verlauf deiner Reise mit Uuna einsehen.
- Über den **Options**-Button im Log-Fenster gelangst du zu weiteren Modulen wie dem Aura-Tracker, Debug-Log und Quest-Tracker.

## Installation

1. Lade das Addon herunter.
2. Kopiere den Ordner `UunaWantSomething` in deinen World of Warcraft Addon-Ordner:
   `_retail_/Interface/AddOns/`
3. Starte das Spiel neu oder lade dein Interface mit `/reload` neu.
